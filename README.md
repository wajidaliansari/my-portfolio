# 🚀 Wajid Ali Ansari 

A modern, high-performance, dark-themed professional portfolio built for an AI Engineer. It highlights production machine learning systems, research papers, technical skills, and interactive project workflows.

## 🛠️ Tech Stack & Tools

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** Vercel
- **Core Languages:** Python, JavaScript, SQL
- **AI/ML Tooling:** LangChain, LangGraph, TensorFlow, PyTorch, FastAPI, Streamlit

## ✨ Features

- **Dark SaaS Aesthetic:** Clean glassmorphism cards, glowing ambient orbs, and a technical dot-grid background.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop screens.
- **Direct Resume Access:** Integrated downloadable PDF resume and quick contact badges.
- **Comprehensive Sections:** Featured Work, Experience, Certifications, Publications, and Education.
